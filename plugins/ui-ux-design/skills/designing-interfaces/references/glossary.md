## Layout and space

| Term | Meaning |
|---|---|
| Alignment | Placing elements along shared edges or centers so they look related |
| Baseline grid | A vertical rhythm on which lines of text sit |
| Bleed / full-bleed | Content that runs to the edge of the screen or container, ignoring margins |
| Column grid | Vertical columns used to align layout (4 on mobile, 8 on tablet, 12 on desktop) |
| Container | A width-limited wrapper that centers content (`max-w-7xl mx-auto`) |
| Density | How much content fits per area: compact, default, comfortable |
| Gutter | Space between grid columns |
| Hierarchy | The order in which users notice things, controlled by size, weight, color, position and space |
| Inset / padding | Space inside an element's border |
| Margin | Space outside an element, or the edge space of a layout |
| Negative space / whitespace | Empty space used deliberately to separate and emphasize |
| Optical alignment | Adjusting position so things *look* aligned, even if not mathematically |
| Proximity | Items close together are perceived as related |
| Rhythm | Repetition of consistent spacing that makes a layout feel ordered |
| Spacing scale | The fixed set of allowed spacing values (4, 8, 12, 16, 24…) |

## Typography

| Term | Meaning |
|---|---|
| Cap height / x-height | Height of capital letters / of lowercase letters like "x" |
| Display type | Very large text for heroes and titles |
| Font weight | Thickness of letterforms (100–900; 400 regular, 600 semibold) |
| Kerning | Space between specific letter pairs (AV, To) |
| Leading / line-height | Vertical distance between lines of text |
| Measure | Line length, usually counted in characters |
| Modular scale | Font sizes generated by multiplying by a ratio (1.25, 1.333) |
| Optical size | Letterform adjustments for small vs large sizes (the `opsz` axis) |
| Orphan / widow | A single word on the last line / a single line at the top of a column |
| Sans-serif / serif / monospace | Without end strokes / with end strokes / every character the same width |
| Tabular figures | Digits of equal width, so columns of numbers align |
| Tracking | Uniform letter-spacing across a run of text |
| Type scale | The fixed set of font sizes a product uses |
| Variable font | A single font file containing a continuous range of weights, widths or other axes |

## Color

| Term | Meaning |
|---|---|
| Accent | The color used sparingly for emphasis and interaction |
| APCA | Advanced Perceptual Contrast Algorithm; a draft contrast method for future WCAG, output as Lc |
| Chroma / saturation | Colorfulness; 0 is gray |
| Contrast ratio | WCAG 2 measure of luminance difference, from 1:1 to 21:1 |
| Gamut | The range of colors a screen or color space can show (sRGB, Display P3) |
| Halation | Glow and blur around bright text on very dark backgrounds |
| Hue | The color family on the color wheel (red, blue…), in degrees |
| Lightness / luminance | Perceived brightness / measured light output |
| Neutral | Grays, often slightly tinted toward the brand hue |
| OKLCH | Perceptually uniform color space: lightness, chroma, hue |
| On-color / foreground token | The color for text and icons placed on a given fill (`--primary-foreground`) |
| Palette / ramp | A set of steps (50–950) of one hue from light to dark |
| Semantic color | A color named by purpose (`--destructive`) rather than appearance (`--red`) |
| Tint / shade | A color mixed with white / with black |
| Tonal elevation | Showing height by making surfaces lighter (common in dark mode) |

## Shape and depth

| Term | Meaning |
|---|---|
| Border radius | Roundness of an element's corners |
| Capsule / pill | A shape whose radius is half its height |
| Concentric radius | Nested corner radii that stay parallel: outer = inner + padding |
| Continuous corner / squircle | A corner whose curvature increases gradually, smoother than a circular arc |
| Divider | A thin line separating content |
| Elevation | Perceived distance of a surface above the page, shown by shadow or tone |
| Scrim | A semi-transparent layer that dims content behind an overlay |
| Stacking context | A CSS layering scope; z-index only competes within one |
| Top layer | Browser layer above all content, used by `<dialog>` and popovers |

## Interaction and states

| Term | Meaning |
|---|---|
| Affordance | What an element lets you do (a button affords pressing) |
| Signifier | The visible cue that communicates an affordance (button shape, underline) |
| Active / pressed | State while a control is being pressed |
| Disabled | Not currently usable; not focusable |
| Focus / focus-visible | The element receiving keyboard input / focus styling shown only when useful (keyboard) |
| Hover | Pointer is over an element (not available on touch) |
| Hit area / target | The interactive region, which can be bigger than the visible shape |
| Indeterminate | A partial state (checkbox with some children checked, a progress bar without a known end) |
| Loading / busy | Waiting for a result |
| Microinteraction | A small, single-purpose interaction with feedback (toggle, like) |
| Optimistic update | Showing the result before the server confirms it |
| Read-only | Visible and copyable but not editable |
| State layer | A translucent overlay showing hover and pressed states (Material) |

## Components

| Term | Meaning |
|---|---|
| Accordion | Stacked headers that expand to reveal content |
| Alert / banner | Persistent message about the state of a section or page |
| Badge | Small read-only label for status or count |
| Bottom sheet | Panel sliding up from the bottom edge, common on mobile |
| Breadcrumbs | Trail of links showing location in a hierarchy |
| Chip | Compact element for filters, choices or entered values |
| Combobox | Text input with a filtered list of options |
| Command palette | Keyboard-driven search for actions and destinations (⌘K) |
| Dialog / modal | Overlay that requires interaction before returning to the page |
| Drawer / side sheet | Panel sliding in from a screen edge |
| Empty state | What a view shows when it has no content |
| Listbox | Selectable list of options |
| Navigation rail | Narrow vertical bar of icon+label destinations (tablet) |
| Popover | Anchored floating panel that can hold interactive content |
| Segmented control | A row of mutually exclusive options joined together |
| Skeleton | Gray placeholder in the shape of content that's loading |
| Snackbar / toast | Brief, auto-dismissing message, optionally with one action |
| Stepper | Indicator of progress through a multi-step flow |
| Switch | On/off control that takes effect immediately |
| Tabs | Controls that switch between panels of the same context |
| Tooltip | Small label shown on hover or focus |

## Responsive

| Term | Meaning |
|---|---|
| Adaptive layout | Distinct layouts per size class |
| Breakpoint | Width at which the layout changes |
| Container query | Styling based on the size of a parent container, not the viewport |
| Fluid | Sizes that scale continuously with the viewport (`clamp()`, `vw`) |
| Mobile-first | Writing base styles for small screens and adding rules for larger ones |
| Reflow | Content rearranging to fit a narrow viewport without horizontal scrolling |
| Safe area | The part of the screen not covered by notches, rounded corners or the home indicator |
| Size class | A width range (compact, medium, expanded) that a layout adapts to |
| `dvh` / `svh` / `lvh` | Dynamic / small / large viewport height units (mobile toolbar aware) |

## Accessibility

| Term | Meaning |
|---|---|
| Accessible name | What assistive technology announces for an element |
| ARIA | Attributes that add roles, states and properties for assistive technology |
| Assistive technology | Screen readers, switch devices, magnifiers, voice control |
| Forced colors | OS high-contrast mode that overrides site colors |
| Inert | Not focusable or interactive (the `inert` attribute) |
| Landmark | Page region (header, nav, main, footer) that screen readers can jump to |
| Live region | Area whose changes are announced automatically |
| Roving tabindex | Keyboard pattern where one item in a group is tabbable and arrows move between items |
| Screen reader | Software that reads the interface aloud or to braille |
| Skip link | Link that jumps keyboard users past navigation to the main content |
| WCAG | Web Content Accessibility Guidelines; levels A, AA, AAA (AA is the usual legal target) |

## UX and research

| Term | Meaning |
|---|---|
| Card sorting | Users group topics into categories to inform navigation |
| Cognitive load | Mental effort required to use an interface |
| Dark pattern | A design that tricks users into actions against their interest |
| Heuristic evaluation | Expert review against usability principles |
| Information architecture (IA) | How content and features are organized and labeled |
| Jobs to be done | The underlying goal a user hires a product for |
| Mental model | What users believe about how something works |
| Microcopy | Small UI text: labels, buttons, errors, hints |
| Progressive disclosure | Showing advanced options only when needed |
| Usability test | Watching real users attempt real tasks |
| User flow | The sequence of screens and steps to complete a task |
| Wireframe / mockup / prototype | Low-fidelity structure / high-fidelity static design / interactive simulation |

## Tokens and systems

| Term | Meaning |
|---|---|
| Component token | A token used by one component (`--button-h`) |
| Design system | Tokens, components, patterns and guidelines shared across a product |
| DTCG | W3C Design Tokens Community Group format (JSON) |
| Primitive token | A raw value (`--blue-600`) |
| Semantic token | A token named by purpose (`--primary`) that points to a primitive or value |
| Theme | A set of token values (light, dark, brand) |
| Variant | A predefined style option of a component (primary, secondary) |
